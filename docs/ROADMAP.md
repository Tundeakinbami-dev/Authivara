# SaaS delivery roadmap

## Phase 1 — Trusted evidence foundation

- Passkey accounts, individual workspaces, local streaming SHA-256, canonical proof envelopes
- Append-only PostgreSQL evidence log and idempotent registration API
- Batched Merkle anchoring, transaction reconciliation, independent certificate verifier
- Private-by-default proofs, share links, version history, evidence export
- Nigerian launch: NGN pricing through a locally suitable payment provider, low-bandwidth mode, mobile-first registration, and clear local legal-language review

Exit criteria: external security review, independently reproducible verification, measurable anchor finality SLO, tested backup recovery, and no claim that the product registers copyright.

## Phase 2 — Professional workflows

- Verified identity tiers, organisation roles, bulk registration, API and webhooks
- Licence records with e-signature-provider integration and version-pinned terms
- C2PA content credentials, creator declarations for AI use/training, and origin metadata
- Agency/client approvals, publisher exports, registry-reference attachments, and disputes

## Phase 3 — Global provenance network

- Regional data residency, SSO/SCIM, retention policies, multi-currency billing, localisation
- Multiple independent timestamp anchors, public transparency log, partner verifier SDKs
- Marketplace and platform integrations, monitoring candidates, evidence bundles, and case workflows

Automated similarity matches must be labelled as leads, never as definitive infringement findings. Human review remains required before notices or enforcement actions.

## Commercial model

- **Free:** limited monthly proofs and public verification
- **Creator:** increased proofs, versions, private shares, evidence exports
- **Studio:** teams, approval workflows, bulk tools, licences, API allowance
- **Enterprise:** SSO/SCIM, data residency, custom retention, SLA, dedicated anchoring policy

Price against verified workflow value and storage/anchoring cost. Avoid per-file blockchain transactions; batch with Merkle roots to make pricing predictable and reduce energy/cost narratives.
